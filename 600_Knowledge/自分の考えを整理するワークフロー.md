# RaindropからObsidianへの取り込み運用

このノートは、サイドチャットで決めたRaindropとObsidianの連携内容を記録する。

## 目的

Raindropで保存したページのうち、`Obsidian`タグを付けたものを、Obsidianの`300_Input`へ取り込む。

取り込んだノートは、既存の`300_Input`内のWeb Clipper由来ノートに近いfrontmatter形式で保存する。

## Web Clipperとの関係

Raindropのタグを検知して、外部からObsidian Web Clipperを直接クリックする標準連携はない。

そのため、基本方針は次の通りとする。

```text
RaindropのObsidianタグ
  ↓
Raindrop APIで対象ページを取得
  ↓
Obsidian Input形式のMarkdownを生成
  ↓
300_Inputに保存
```

Web Clipperの物理的な自動クリックではなく、Web Clipperで作られるノートに合わせたMarkdownを直接生成する。

## 取り込みスクリプト

```text
scripts/import_raindrop_obsidian_tag.py
```

### 動作

- Raindropの全コレクションから`Obsidian`タグ付き項目を取得
- `Obsidian`タグは大文字・小文字を区別しない
- ページURLをもとに`300_Input`へMarkdownを生成
- 既存の`source` URLと一致するノートはスキップ
- 既存ファイルは上書きしない
- `raindrop_id`を重複防止・出典確認用に保存
- 取り込み後、Raindrop側に`ObsidianImported`タグを追加
- `ObsidianImported`タグ付きの項目は次回以降スキップ
- 既にObsidianへ取り込み済みだが完了タグがない項目も、URL重複判定後に完了タグを追加

### 未取り込み・取り込み済みの区別

Raindrop側のタグを次のように使い分ける。

- `Obsidian`：Obsidianへ取り込みたい項目
- `ObsidianImported`：取り込み済みの項目

`Obsidian`タグは残したまま`ObsidianImported`を追加するため、元の用途を失わず、完了状態も確認できる。取り込み対象の一覧は、Raindrop側で`Obsidian`を検索し、`ObsidianImported`が付いていないものとして扱う。


## RaindropタグとObsidianタグの対応

`Obsidian`は取り込み用のトリガーであり、Obsidian側の`tags`には保存しない。

| Raindropタグ | Obsidianタグ |
| --- | --- |
| `コミュニケーション` | `🎁Topic/Life` |
| `名文` | `🎁Topic/Rhetoric` |
| `例え` | `🎁Topic/Rhetoric` |

対応表にないタグは、原則として次のように変換する。

```text
Life → 🎁Topic/Life
```

すでに`Topic/...`や`🎁Topic/...`形式になっているタグは、Vaultの形式に合わせて保持する。

空白を含むタグは、Obsidianタグとして扱えるようにハイフンへ変換する。

## 本文抽出

DefuddleをCLIとしてインストール済み。

```text
/Users/isikurahiromitu/.local/share/mise/installs/node/lts/bin/defuddle
```

取り込み時にDefuddleが利用可能なら、対象ページの本文をMarkdownとして抽出する。

本文抽出に失敗した場合は、Raindropに保存されている次の情報を使う。

- excerpt
- note
- highlights

## 実行方法

アクセストークンは環境変数で設定し、ファイルやチャットに書かない。

```bash
export RAINDROP_ACCESS_TOKEN="Raindropのアクセストークン"
```

初回はdry-runで確認する。

```bash
python3 scripts/import_raindrop_obsidian_tag.py --dry-run
```

問題がなければ実際に取り込む。

```bash
python3 scripts/import_raindrop_obsidian_tag.py
```

本文抽出を行わず、Raindropのexcerpt・note・highlightだけを保存する場合は、次のオプションを使う。

```bash
python3 scripts/import_raindrop_obsidian_tag.py --no-fetch
```

取り込み完了タグを付けずに実行する場合は、次のオプションを使う。

```bash
python3 scripts/import_raindrop_obsidian_tag.py --no-mark-imported
```

## Skill

この取り込み処理を自然言語またはSkill名から呼び出せるようにした。

```text
.codex/skills/raindrop-obsidian-import/SKILL.md
```

呼び出し例：

```text
$raindrop-obsidian-import
```

または、次のように依頼する。

```text
RaindropのObsidianタグ付き項目を300_Inputに取り込んで
```

Skillは、初回にdry-runを実行し、対象と生成先を確認してから本取り込みを行う。
