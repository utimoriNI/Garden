# 情報量と二択での探索

## はじめに

出身地を「はい・いいえ」の質問で当てるとき、よくある答えを少ない質問で見つけられるようにすると、平均の質問数を減らせる。

ある答えの珍しさをビットで表したものが**情報量**、答え全体の情報量の平均が**シャノンエントロピー**だ。エントロピーは、条件を満たす二択質問で答えを特定する際の、平均質問数の理論的な下限になる。

## 答え一つの情報量

確率が半分の出来事なら、その答えは1ビットの情報量を持つ。4分の1なら2ビット、8分の1なら3ビット。珍しい答えほど情報量が大きい。

確率を `p` とすると、情報量は `−log₂(p)` ビットで表す。たとえば東京の確率を仮に11.6%とすると、情報量は約3.11ビットになる。

これは「東京と分かるのに必ず4問必要」という意味ではない。「東京都出身？」という質問なら、東京の場合は1問で分かる。ただし、その質問が全候補を通した平均質問数を最小にするとは限らない。

11.6%は説明のための仮定。人口の割合と出身地の割合は同じとは限らず、ツールを使う人の分布とも異なりうる。

## エントロピーと平均質問数

シャノンエントロピーは、各答えの情報量を、その答えが出る確率に応じて平均したもの。式では `H = −Σ pᵢ log₂(pᵢ)` と表す。

たとえばA県が50%、B県とC県がそれぞれ25%の場合、情報量の平均は次のようになる。

`0.5 × 1 + 0.25 × 2 + 0.25 × 2 = 1.5ビット`

答えが正確で、どのような二択質問でも自由に作れるなら、全員の答えを特定する平均質問数は、この値を下回れない。質問は整数回なので、一般には下限とぴったり一致するとは限らない。

## よくある答えから探す

さきほどの3県なら、次の質問で当てられる。

```text
A県出身？
├─ はい → A県（1問）
└─ いいえ → B県出身？
             ├─ はい → B県（2問）
             └─ いいえ → C県（2問）
```

平均質問数は `0.5 × 1 + 0.25 × 2 + 0.25 × 2 = 1.5問`。この例ではエントロピーに一致する。出やすいA県を浅い枝に置くことで、多くの場合を1問で終えられる。

## ハフマン符号化との関係

上の「はい・いいえ」をそれぞれ `0` と `1` に対応させると、A県は `0`、B県は `10`、C県は `11` と表せる。よく出る答えほど短い符号にすることは、よくある答えを少ない質問で見つけることに対応する。

ハフマン符号化は、確率の小さい候補同士から順にまとめて木を作る方法。各候補の確率が分かり、自由な二択質問ができる場合に、平均質問数が最小になる木を作れる。単に人口順に並べて質問する方法とは異なる。

実際の出身地当てツールがハフマン符号化を使っているかは確認できていない。また、東京が3問で当たることだけでは、全候補の平均質問数が最適かどうかは分からない。
