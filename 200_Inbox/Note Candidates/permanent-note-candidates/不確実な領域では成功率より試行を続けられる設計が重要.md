# 不確実な領域では成功率より試行を続けられる設計が重要

> [!info] 承認時の変更
> `600_Knowledge/不確実な領域では成功率より試行を続けられる設計が重要.md` に `type: knowledge` の下書きを1件作成します。元の Fleeting Note は変更しません。

## 提案する主張

努力がそのまま成果に積み上がらない領域では、一回の成功確率を確実にするより、失敗しても学習しながら試行を続けられる状態を設計する方が重要である。

## 下書き

技術や知識の習得では、練習量が能力として蓄積し、次の成功確率を高めやすい。その感覚に慣れていると、人間関係や人生上の選択のように、努力と結果が直線的につながらない領域に強い違和感を覚える。十分に準備すれば成功を確実にできるはずだと考え、確実にならない限り動けなくなるからである。

しかし、不確実な領域で一回ごとの成功率を完全に管理することはできない。そこで管理対象を「成功するか」から「次も試せるか」へ移す。失敗の費用を小さくする、結果から一つ学ぶ、回復の時間を確保する、異なる選択肢を試す、といった設計なら自分で調整できる。

焼きなまし法の比喩は、探索と安定の配分を考える助けになる。可能性と回復力が大きい時期には、短期的に評価が下がる選択も含めて探索範囲を広げる。その後は、得た知見を使って生活の下限や再現性を整える。「トップを上げる」と「ボトムを上げる」は、年齢そのものの規則ではなく、この二つのモードの違いとして読める。

重要なのは、無計画に回数だけを増やすことではない。結果を観察して次の試行を少し変えられること、そして失敗しても可能性が閉じないことが必要である。不確実な領域の努力とは、成功を保証する行為ではなく、学習可能な試行を継続できる条件を守る行為である。

ここで得られるコントロール感は、結果を支配できるという錯覚ではない。時間の使い方、次に試す選択肢、失敗から拾う情報を自分で決められるという感覚である。運は制御できなくても、運が起こりうる場所へ出続けることはできる。挑戦前の全能感を燃料として使い、失敗後の洞察で次の試行を変えることが、その循環を支える。

## 根拠

- [[500_Fleeting/長続きするものと努力の関係性についての考察 - ChatGPT]] — 技術のように努力が蓄積する領域と、人間関係のように達成確率が単純には上がらない領域の違いを示す。
- [[500_Fleeting/焼きなまし法的人生論]] — 若い時期の探索と、時間経過に伴う局所最適化を焼きなまし法で捉えている。
- [[500_Fleeting/ 20代はトップを上げる、30代はボトムを上げるみたいなのが理想]] — 探索による上振れと、安定化による下振れ防止を異なる課題として捉える視点を与える。
- [[500_Fleeting/自分や未来の可能性は充実感の源泉]] — 成功済みの結果だけでなく、未来に試せる可能性そのものが充実感の源になることを示唆する。
- [[300_Input/Reading Notes/動機付けに重要なのは自分が環境をコントロールできているという認知]] — 幸福や動機づけには、結果そのものより、時間や環境に働きかけられるという認知が関わることを示す。
- [[300_Input/Reading Notes/挑戦するまでの全能感は燃料であり、失敗の経験は洞察である]] — 挑戦前の期待と失敗後の学習には異なる役割があり、どちらか一方だけでは試行が続かないことを示す。
- [[300_Input/Reading Notes/運という要素はただの偶然じゃない。望んで行動する人間にしか訪れない戦場のアヤだ]] — 結果の不確実性を認めながら、望む事象が起こる場へ行動し続ける必要性を示す。

## 反例・適用限界

- 医療、安全、重大な金銭判断など、失敗の費用が大きい領域では試行回数を増やす発想をそのまま適用できない。
- 同じ試行を反復するだけでは学習にならない。観察、振り返り、次の変更が必要である。
- 探索期と安定期を年齢だけで固定すると、個人差や環境変化を見落とす。「トップ」と「ボトム」は状況に応じて同時に整えてよい。
