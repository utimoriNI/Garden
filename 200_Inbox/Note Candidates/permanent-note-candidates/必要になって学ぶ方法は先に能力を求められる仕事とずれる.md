# 必要になって学ぶ方法は先に能力を求められる仕事とずれる

## 提案する主張

必要が生じてから学ぶ方法は学習対象を絞れる一方、必要になる前に能力を用意しておくことを求められる仕事では、学び始める時期を別に設計する必要がある。

## 下書き

必要になった情報をその都度取得する学び方では、目の前の課題を手がかりに学習対象を選べる。しかし、自分が必要を感じる時期と、他者から能力を求められる時期は一致するとは限らない。

Fleetingには、自分は必要になった時に勉強する一方、仕事では先にできることを持ち、それが必要になったら提供するためやりにくい、という認識がある。この困り方は、学習意欲の有無だけでなく、能力を用意する時期のずれとして捉えられる。

そこで、目の前の必要から学ぶ対象と、将来提供するために先に触れておく対象を分けるという方針を提案する。すべてを先回りして習得するのは難しいが、必要になってからの学習だけでは間に合わない場面があるなら、その場面に備える時間を別に確保する理由がある。

ただし、現在の自分が役に立つと判断したものだけに対象を絞ると、将来の必要そのものを見落とす可能性もある。有用性を問うときに自分の価値観を前提としてしまうというReading Noteは、その選別の限界を考える材料になる。

この候補は仕事全般を先行学習型だと断定するものではない。本人が感じているやりにくさを、学習と能力提供の時間差から説明する仮説である。どの能力をどれだけ先に用意すべきかは、実際の仕事の要求を見て決める必要がある。

## 根拠

- [[500_Fleeting/自分は最近必要になった時に勉強するスタンスでいるけど、仕事は先にできることを持っておいてそれを必要になったら提供する流れだからやりにくいんだ]] — 本人が認識する学習開始と能力提供の時期のずれを示す。具体的な職務や失敗事例は書かれていない。
- [[300_Input/Reading Notes/遅延評価的勉強法]] — 「遅延評価: 必要になった情報をその都度取得する」。必要を起点に対象を選ぶ学び方の定義を支える。
- [[300_Input/Reading Notes/何の役に立つのかと問う前に自分の価値観が正しいかを疑え]] — 有用性を判断するとき、自分の価値観の正しさを前提としてしまうという指摘。現在の必要だけで学習対象を選ぶことへの留保として使う。

## 反例・適用限界

- 必要が発生してから調査・習得する時間を含む仕事なら、遅延評価的な学習と両立する。
- 先に学んでも使われない知識はある。将来の需要を正確に予測できるとは限らない。
- 本人の認識を支える具体的な業務記録が不足している。先行学習の効果や最適な配分は未検証。
