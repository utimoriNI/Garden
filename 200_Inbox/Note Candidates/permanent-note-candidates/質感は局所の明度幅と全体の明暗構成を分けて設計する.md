# 質感は局所の明度幅と全体の明暗構成を分けて設計する

> [!info] 承認時の変更
> `600_Knowledge/質感は局所の明度幅と全体の明暗構成を分けて設計する.md` に `type: knowledge` の下書きを1件作成します。元の Fleeting Note と既存のイラストノートは変更しません。

## 提案する主張

狙った質感を描くには、各パーツ内の明度差と画面全体の明暗差を同じものとして強めず、局所の明度幅を抑えながら全体の領域配分でコントラストを作る必要がある。

## 下書き

絵にコントラストを出そうとして、白い服、肌、髪など各パーツの内部にそれぞれ強い明暗差をつけると、画面全体が細かく光り、ツヤや水彩のような質感が生まれやすい。マットでさらっとした印象を狙う場合、必要なのはコントラストをなくすことではなく、コントラストを置く階層を変えることである。

まず、各パーツの内部では明度の幅を抑え、固有色のまとまりを保つ。次に、明るい領域と暗い領域の面積、光が集中する場所、画面全体のキーによって大きな明暗差を作る。すると個々の面は落ち着いたまま、絵全体には明確な光の方向と強弱が生まれる。

この区別は、環境光と固有色を調和させるときにも有効である。固有色ごとに独立した明暗を作るのではなく、先に画面を支配する光の色と明暗構成を決め、その範囲の中で固有色を変化させる。画像を「光」「明度」「色」「領域」の要素に分解して観察すると、参考画像のコントラストが局所にあるのか全体にあるのかを切り分けやすい。

したがって、質感の問題をブラシやテクスチャだけで解決しようとせず、局所の明度幅と全体の明暗構成を別々に診断するべきである。局所は素材の落ち着きを、全体は画面の読みやすさと光の印象を担う。

診断するときは、色を外した白・グレー・黒の複数案に塗り分けるとよい。色相や彩度に隠れていた明暗設計が露出し、問題がパーツ内の幅にあるのか、全体の領域配分にあるのかを比較しやすくなる。

- [[500_Fleeting/画像の要素分解]] — 画像をバリュー、光、色、エッジなどの別要素として観察する枠組みを与える。

## 反例・適用限界

- 質感は明度だけで決まらず、エッジ、反射、彩度、ブラシ跡、表面の細部にも左右される。
- 局所の明度幅を狭める方法はマットな表現には有効だが、金属、濡れた面、強い逆光などにはそのまま適用できない。
- 「明度差を20程度にする」といった数値は特定の絵に対する仮説であり、普遍的な規則ではない。
