# Theme Discovery Index

This index lists agent-generated discovery artifacts for the current theme-discovery system.

The primary thematic layer is:

- `Life`
- `Society`
- `Learning`

These three tags are treated as the main LLM wiki source layer for discovering mid-level themes and growing MOCs.

- [[998_Resource/AgentWiki/theme-discovery/clusters/life-society-batch-01|life-society-batch-01]]
  - First clustering pass for 24 `Life x Society` reading-notes. Bundles center on metricized evaluation, utility flattening, norm-shaping, self-responsibilization, and social friction.

## Theme Proposals

- [[998_Resource/AgentWiki/theme-discovery/themes/life-society-proposals-01|life-society-proposals-01]]
  - First theme proposal pass. Promotes 3 cluster bundles into mid-level candidates around metricized value, norm-shaped feeling/body, and self-responsibilization.
